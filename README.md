# 💻 Sahan Maduranga – Personal Portfolio Website

**Sahan Maduranga Portfolio** is a modern and responsive personal website created to showcase my skills, education, services, projects, and experience as an ICT undergraduate and Junior Full Stack Developer.

---

## 🧭 Project Overview

This portfolio provides a professional online presence where visitors can learn about my technical and creative skills, explore my projects, and contact me.

---

## 🔑 Key Features

* 🏠 **Home Page** – Personal introduction and social links
* 👨‍💻 **About Me** – Background, education, and career goals
* 🛠️ **Skills** – Technical and creative skills
* 💼 **Services** – Web Development, Graphic Design, UI/UX, and Video Editing
* 🚀 **Projects** – Showcase of my main projects
* 🖼️ **Project Gallery** – Interactive project image slider
* 📱 **Responsive Design** – Works on desktop and mobile
* 📩 **Contact Form** – Contact form powered by EmailJS
* ✨ **Modern UI** – Dark theme with animations and smooth navigation
